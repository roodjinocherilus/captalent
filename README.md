# Cap Talent Lab

Static website for Cap Talent Lab, the Salon de l'Emploi du Cap-Haitien and talent/employer platform for Haiti's Grand Nord.

## Project Structure

- `index.html` - single-page site with embedded styles and scripts
- `images/` - event photography and poster assets
- `logo/` - partner and brand logos
- `videos/` - local event videos

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static web server.
